# Candidatos a Novas Specs — Hub Manager Tour

> Ideias com impacto alto o suficiente para merecer módulo/spec 
> própria (não backlog de pequena melhoria), ainda sem planejamento 
> formal. Registradas aqui para não se perderem, sem compromisso de 
> prazo.

## Mapa de palco gráfico (benchmarking tecrider.com)
Editor visual de drag-and-drop para montagem do mapa de palco, 
inspirado no tecrider.com (Stage Plot Maker). Complementaria o Rider 
Técnico atual, hoje só em lista.

## Integração com sistema de contabilidade
Exportação/sincronização de dados financeiros (reembolsos, valores de 
rider) para sistema de contabilidade externo. Sistema específico ainda 
não definido.

## Emissão de nota fiscal
Emissão fiscal real (integração com SEFAZ/certificado digital), 
possivelmente ligada aos reembolsos ou a um futuro módulo de 
monetização da plataforma. Tem implicação legal/fiscal — exige 
levantamento de requisitos regulatórios antes de qualquer desenho 
técnico, não é tarefa de código direta.
